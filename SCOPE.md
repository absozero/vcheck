# Project Scope Document

This document details the scope of the Vcheck project, listing the different levels of deliverables.

## Overarching Goal - Mission Statement

Vcheck must be able to manage release versions for multiple git cloud providers and provide notifications on releases as necessary.

### Sub-Goals

- It must be reasonably fast to use
- It must focus on managing the version and allowing the user to choose the managed binary's installation.
- It must be expandible farther than the intended purpose of checking the version.
- It must be future proof as long as the upstream API spec remains the same.
- The tool's development must follow best agile practices
